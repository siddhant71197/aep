# AEP Plan Guide

A chat agent that helps people during Medicare's Annual Enrollment Period (Oct 15 – Dec 7). It asks about their current plan, answers questions, and suggests plans. It also shows an insurance ad inside the chat that opens a lead form (name, email, ZIP).

- **Stack:** Next.js (App Router, TypeScript, Tailwind)
- **LLM:** Replicate `google/gemini-3.5-flash`; every assistant message is generated by Gemini
- **Plan data:** mock catalog in `lib/plans.json`, ranked by `lib/planEngine.ts`
- **Rule:** at least one plan suggestion every 3 user messages (`lib/cadence.ts`, enforced on the server)
- **Leads:** saved to `data/leads.json`, listed at `GET /api/leads` (no auth, local use only)

## Setup

```bash
npm install
cp .env.example .env.local   # then put your Replicate token in .env.local
npm run dev
```

`.env.local` is git-ignored. Never put a real token in `.env.example` or any committed file.
